# ユースケース

| 業務領域       | 主な利用者                   | 達成すること                                         | 仕様                                                        |
| -------------- | ---------------------------- | ---------------------------------------------------- | ----------------------------------------------------------- |
| 来場者向け情報 | 来場者                       | 出店情報、メニュー、スポンサー情報を確認する         | [`visitor-information.md`](../specs/visitor-information.md) |
| 注文・会計     | 会計担当者                   | 注文内容を入力し、金額と在庫を確認して注文を確定する | [`sales.md`](../specs/sales.md)                             |
| 在庫           | 会計担当者、許可された担当者 | 販売可否を確認し、注文と在庫を一致させる             | [`inventory.md`](../specs/inventory.md)                     |
| 調理           | 調理担当者                   | 確定した注文を確認し、調理状況を更新する             | [`kitchen.md`](../specs/kitchen.md)                         |
| 受け渡し       | 受け渡し担当者               | 完成した注文を照合し、二重に渡さず完了する           | [`handoff.md`](../specs/handoff.md)                         |
| 当日運用       | 各担当者、出店責任者         | 開店準備、例外対応、閉店処理を行う                   | [`operations.md`](../specs/operations.md)                   |
