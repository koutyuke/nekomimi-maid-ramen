# 利用者

| 利用者         | システムに関する役割                                               | 必要な情報・判断                             |
| -------------- | ------------------------------------------------------------------ | -------------------------------------------- |
| 来場者         | 出店情報の確認、注文内容の口頭伝達、商品の受け取り                 | メニュー、価格、売り切れ、合計金額、注文番号 |
| 会計担当者     | 注文内容の入力、在庫確認、現金の受け取り、注文確定、注文番号の案内 | 在庫、注文内容、合計金額、お釣り、確定結果   |
| 調理担当者     | 確定した注文の確認、調理状況の更新                                 | 注文番号、商品、数量、調理状況               |
| 受け渡し担当者 | 完成品と注文番号の照合、商品の受け渡し                             | 完成した注文の番号、内容、受け渡し状況       |
| 出店責任者     | 業務内容と当日の運用に関する情報提供、決定内容の確認               | 要件、未決事項、提供範囲、受け入れ結果       |
| 開発担当者     | 要件・仕様・運用の最終決定、設計、実装、検証、当日の技術支援       | 要件、仕様、利用環境、運用上の制約           |

上表は業務上の役割であり、システムが操作を制限する単位ではない。システムはOwner、Admin、Staff、Noneの4つのロールで制限する。認証方式とロールの操作範囲は[`DEC-SYS-002`](../meta/decisions/DEC-SYS-002-staff-access.md)で定める。

最終決定者と承認方法は、[`DEC-SYS-001`](../meta/decisions/DEC-SYS-001-requirement-approval.md)で定める。
