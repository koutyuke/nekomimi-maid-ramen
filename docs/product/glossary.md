# 用語

| 用語         | 定義                                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 注文候補     | 会計担当者が画面へ入力した注文確定前の内容。在庫は確保しない。                                                                     |
| 注文確定     | 会計担当者が内容と在庫を確認して確定操作を行い、正式な注文を成立させること。注文番号の発行、在庫の減算、調理担当者への共有を伴う。 |
| 注文番号     | 確定した注文を識別し、商品の受け渡しまで照合に使う重複しない番号。会計担当者が紙へ手書きして来場者へ渡す。                         |
| 売り切れ     | 商品の在庫がなく、販売できない状態。                                                                                               |
| 調理状況     | 確定した注文について、調理担当者が確認・更新する作業の進み具合。                                                                   |
| 受け渡し済み | 受け渡し担当者が注文番号を照合し、来場者へ商品を渡した後の注文の状態。                                                             |
