# 用語

| 用語         | 定義                                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 注文候補     | 会計担当者が画面へ入力した注文確定前の内容。在庫は確保しない。                                                                     |
| 注文確定     | 会計担当者が内容と在庫を確認して確定操作を行い、正式な注文を成立させること。注文番号の発行、在庫の減算、調理担当者への共有を伴う。 |
| 注文番号     | 確定した注文を識別し、商品の受け渡しまで照合に使う番号。営業日ごとに1から始まる連番で、会計担当者が紙へ手書きして来場者へ渡す。    |
| 売り切れ     | 商品の在庫がなく、販売できない状態。                                                                                               |
| 調理状況     | 確定した注文について、調理担当者が確認・更新する作業の進み具合。未調理、調理中、完成の3つがある。                                  |
| 受け渡し済み | 受け渡し担当者が注文番号を照合し、来場者へ商品を渡した後の注文の状態。                                                             |
| ロール       | システムが操作を制限する単位。Owner、Admin、Staff、Noneの4つがある。業務上の役割とは別に管理する。                                 |
| Owner        | 開発担当者が持つロール。Adminと同じ操作ができ、設定として固定されるため画面からは変更できない。                                    |
| Admin        | Staffの全操作に加え、在庫の修正、確定した注文の訂正と取り消し、ロールの付与と剥奪を行えるロール。                                  |
| Staff        | 注文の入力と確定、調理状況の更新、受け渡しの完了を行えるロール。ロールの操作はできない。                                           |
| None         | 初回ログイン時の初期ロール。公開ページ以外を利用できない。                                                                         |
