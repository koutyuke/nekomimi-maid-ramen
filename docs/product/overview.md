# プロジェクト概要

## 目的

文化祭のクラス出店「猫耳メイドラーメン」において、来場者への情報提供と、注文受付から調理、受け渡しまでの連携を支援する Web アプリケーションを作成する。

注文内容、金額、在庫、調理状況、受け渡し状況を担当者間で共有し、注文漏れ、会計ミス、過剰販売、受け渡し間違いを減らす。来場者は、来店前や待機中に出店情報と販売可能な商品を確認できる。

## 開催条件

文化祭は2026年10月末に開催する。正確な開催日、営業時間、想定する来場者数と注文数は[`Q-OPS-002`](../meta/questions/Q-OPS-002-event-conditions-and-load.md)で決定する。

## 背景

口頭だけで注文を会計から調理へ伝える運用では、注文漏れや取り違えが発生しやすく、担当者が同じ注文状況を確認できない。手計算による会計ミス、在庫切れ商品の受付、注文と来場者を照合できないことも想定される。

店頭掲示だけでは、来場者が店へ着く前にメニューや売り切れを確認できない。本システムは、これらの情報と業務状態を共有する手段を提供する。

## 対象範囲

- 出店場所、営業時間、メニュー、スポンサー情報の公開
- 会計担当者による商品と個数の入力、在庫確認、注文確定
- 合計金額とお釣りの計算
- 注文番号の発行、在庫更新、調理担当者への注文共有
- 調理状況の確認と更新
- 注文番号を使った受け渡しの照合
- 文化祭当日の運用と例外対応

## 対象外

- 来場者のユーザー登録とログイン
- オンライン決済
- スポンサーとの契約や材料調達
- 調理と食品衛生の手順
