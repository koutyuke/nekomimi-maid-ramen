# 体験

来場者は、来店前または待機中に出店情報と販売可能な商品を確認する。注文兼会計口では、注文する商品と個数を会計担当者へ伝える。

会計担当者は、聞き取った内容を画面へ入力し、商品、個数、合計金額、在庫を来場者と確認する。注文を確定すると、注文番号が発行され、調理担当者へ注文内容が共有される。

調理担当者は、確定した注文を確認して調理状況を更新する。商品が完成したら、受け渡し担当者が注文番号を照合して来場者へ商品を渡す。

現金を受け取る時点、確定後の訂正、障害時の代替運用など、判断が必要な事項は[`meta/questions/`](../meta/questions/)で管理する。
