# メニュー

提供する商品は次の6品である。

| 表示順 | 分類       | 商品名           | 価格  |
| ------ | ---------- | ---------------- | ----- |
| 1      | ラーメン   | ラーメン         | 500円 |
| 2      | 餃子       | 餃子             | 400円 |
| 3      | 瓶ジュース | コーラ           | 300円 |
| 4      | 瓶ジュース | オレンジジュース | 300円 |
| 5      | 瓶ジュース | ジンジャーエール | 300円 |
| 6      | 瓶ジュース | 烏龍茶           | 300円 |

「瓶ジュース」は表示上の分類であり、4種類はそれぞれ独立した商品として在庫を持つ。販売開始時は全商品を販売可能とする。

営業中に価格を変更した場合も、確定済みの注文には確定時の価格を適用する。詳細は[注文・会計仕様](../specs/sales.md)で定義する。

各商品の説明文とアレルギー情報は営業開始前に登録し、[運用仕様](../specs/operations.md)の開店前確認で原材料表示と照合する。
