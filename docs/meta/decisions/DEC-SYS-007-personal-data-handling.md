# DEC-SYS-007 個人情報の保持と公開窓口

## 結論

運営主体の公開名は「猫耳メイドラーメン運営チーム」、問い合わせ先は`ac25302@gm.ibaraki-ct.ac.jp`とする。開発担当者が問い合わせと削除を担当する。

スタッフのプロフィールと認証情報は2027年3月31日までに削除する。本人からの削除依頼をメールで受け付け、本人確認後14日以内を目安に対応する。セッションの有効期間は12時間のままとし、失効と保存データの削除を分ける。

利用規約は来場者による公開サイトの利用とスタッフ機能の利用を対象にする。アカウント管理と業務操作の条項はスタッフに限って適用する。

## 理由

一時的なイベントのため、イベント後の開発・確認と問い合わせ対応のため、当該年度内の利用に限って保存する。問い合わせと削除を本番環境へアクセスできる開発担当者へ集約する。

## 影響

保存項目は[システム共通仕様](../../specs/system-wide.md)の`SPEC-SYS-007`、削除作業は[運用仕様](../../specs/operations.md)の`SPEC-OPS-004`を正本とする。復旧用履歴の残存期間も公開ポリシーへ記載する。注文や在庫などの保持期間は、この判断の対象に含めない。
