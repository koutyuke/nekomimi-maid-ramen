# PLAN-SAL-001 Web注文内容事前選択

## 目的と対象利用者

来場者が注文兼会計口へ到着する前に商品と個数を入力し、会計担当者の入力作業と転記ミスを減らす計画である。

## 境界

対象は、販売可能な商品の表示、商品と個数の選択・変更・削除、小計と合計金額の表示、連携可能な事前選択内容の作成である。

事前選択内容は正式な注文ではない。注文番号の発行、在庫の確保・減算、決済、来場者の登録・ログインは行わない。

## 想定する体験

1. 来場者がWeb上でメニューと販売可否を確認する。
2. 商品と個数を選択し、小計と合計金額を確認する。
3. 注文と在庫を変更せず、会計へ渡せる事前選択内容を作成する。

## 実現可能性

既存のメニュー情報と注文候補の入力項目を利用できる想定である。会計画面へ渡す方法は[`PLAN-SAL-002`](PLAN-SAL-002-qr-order-transfer.md)で扱う。

## 要件にする前に決めること

- 選択できる商品種類数と商品ごとの個数上限
- 在庫表示の更新頻度と、表示後に在庫が変化した場合の案内
- 価格変更後に古い事前選択内容を表示する方法
- 戻る、再読み込み、複数タブを使用した場合の扱い
- 対応するスマートフォン、ブラウザー、画面サイズ、利用言語
- 利用者試験の対象者、完了時間、成功率
