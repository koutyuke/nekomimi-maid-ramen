# Q-OPS-002 開催条件と業務量

## 問い

開催日、営業時間、来場者数、通常時とピーク時の注文数、商品数、各担当人数、端末台数を決める。開催時期は2026年10月末である。

## 影響

性能目標、必要端末、リハーサル条件、開発と受け入れの日程を確定できない。

期限は未定である。
