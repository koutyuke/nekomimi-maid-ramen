# Q-SYS-004 対応端末・ブラウザー・ネットワーク

## 問い

来場者とスタッフの対象端末、ブラウザー、画面サイズ、店内ネットワーク、予備回線、電源、予備端末を決める。

## 影響

公開画面とスタッフ画面の試験条件、利用可能性、障害時の設計を確定できない。

決定者と期限は未定である。
