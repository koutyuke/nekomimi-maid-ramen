# Q-OPS-004 当日運用の担当者と判定基準

## 問い

開店前、営業中、閉店後の各確認について、担当者、実施時刻・頻度、異常と判断する基準、修正権限、連絡先を決める。

## 影響

担当者と基準が決まらないと、運用仕様を当日の手順として実行できず、異常の見落としや無断修正が発生する可能性がある。

期限は未定である。
