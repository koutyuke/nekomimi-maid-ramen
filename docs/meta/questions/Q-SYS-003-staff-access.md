# Q-SYS-003 スタッフの認証と権限

## 問い

スタッフ画面を利用できるネットワーク、認証方法、役割ごとの権限、共用端末、緊急時の権限回復を決める。

## 影響

第三者や権限のない担当者による注文、在庫、調理状況、受け渡し状況の変更を防ぐ水準が決まらない。

決定者と期限は未定である。
