# Q-SYS-005 可用性・性能・使いやすさの目標値

## 問い

次の測定条件と合格値を決める。

- 営業時間中に許容する停止回数と停止時間
- 注文確定の応答時間と、その時間内に完了する割合
- 確定注文が調理画面へ反映されるまでの時間
- 会計操作の利用者試験に参加する対象者と人数
- 注文入力から確定までの成功率と完了時間
- 文字サイズ、コントラスト、キーボード操作、読み上げ対応の基準

## 影響

品質要件を満たしたか客観的に判定できず、本番相当の受け入れ条件を確定できない。

決定者と期限は未定である。
