# Q-SAL-003 確定後の訂正・取り消し・返金

## 問い

確定後の内容変更、取り消し、返金、在庫の復元、調理開始後の扱い、実行できる担当者を決める。

## 影響

手順がないと、注文、在庫、現金、調理状況の間に不整合が生じる。

決定者と期限は未定である。
