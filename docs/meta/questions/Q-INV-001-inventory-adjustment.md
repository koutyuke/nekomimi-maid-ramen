# Q-INV-001 在庫の初期登録と修正

## 問い

初期在庫を登録する担当者と方法、営業中に在庫を修正できる担当者と条件、修正履歴、負数と上限の扱いを決める。

## 影響

販売開始時の在庫を用意できず、実在庫との差が生じた場合の復旧方法も確定できない。

期限は未定である。
