# Q-VIS-002 商品名と価格

## 問い

公開サイトとスタッフの会計で使う商品名と価格を決める。

## 選択肢と影響

| 項目           | [メニュー](../../product/menu.md) | 公開サイトのデザイン |
| -------------- | --------------------------------- | -------------------- |
| ラーメン       | 500円                             | 600円                |
| 餃子           | 400円                             | 300円                |
| オレンジの飲料 | オレンジジュース                  | オレンジ             |

決まるまでは、公開サイトもメニューの値を使う。デザインの値を採用する場合は、メニュー、公開サイトの商品データ、`apps/api/seed.sql`をあわせて変更する。公開サイトとスタッフの会計は商品データを別々に持つため、片方だけを変更すると来場者に見せる価格と会計の価格が食い違う。

## 決定に必要な情報

出店責任者が決めた販売価格と、来場者に見せる商品名。
