# Q-KIT-001 調理状況と遷移

## 問い

必要な調理状況、各状態を更新する担当者、状態を戻す操作、取り消し注文の扱い、一覧の並び順を決める。

## 影響

調理画面と受け渡し画面の振る舞い、および二重作業を防ぐ方法を確定できない。

期限は未定である。
