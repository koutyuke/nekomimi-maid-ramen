# 来場者向け情報仕様

## 結論と対象範囲

来場者は、ログインせずに出店情報、メニュー、スポンサー情報を確認できる。この仕様は情報の内容と表示結果を定義し、画面の配置や配色は定義しない。

## 管理データと画面

| 情報           | 必要な項目                           | 主な画面       |
| -------------- | ------------------------------------ | -------------- |
| 出店情報       | 出店名、場所、営業時間、案内文       | 出店案内       |
| 商品           | 商品名、説明、価格、表示順、販売可否 | メニュー       |
| スポンサー情報 | 承認された名称、紹介文、画像、リンク | スポンサー紹介 |

商品と価格は[`Q-VIS-002`](../meta/questions/Q-VIS-002-menu-content.md)、スポンサーの掲載項目は[`Q-VIS-001`](../meta/questions/Q-VIS-001-sponsor-content.md)で決定する。

## SPEC-VIS-001 出店情報を表示する

関連要件: `REQ-VIS-001`

未ログインの来場者が出店案内を開いたとき、合意した出店場所と営業時間を表示する。来場者のユーザー登録やログインは要求しない。

### 受け入れ例

1. ログインしていない端末で出店案内を開く。
2. 合意した出店場所と営業時間が表示される。

## SPEC-VIS-002 メニューと販売可否を表示する

関連要件: `REQ-VIS-002`、`REQ-INV-001`

メニューには、登録された商品の名称、価格、説明、販売可否を表示する。販売可否は現在の在庫に基づき、色だけに依存せず識別できるようにする。

### 受け入れ例

1. 販売可能な商品と在庫切れの商品を用意する。
2. メニューを開く。
3. 各商品の名称、価格、説明が表示され、在庫切れの商品を文字または記号でも識別できる。

## SPEC-VIS-003 承認されたスポンサー情報を表示する

関連要件: `REQ-VIS-003`

スポンサー紹介には、掲載を承認された情報だけを表示する。承認されていない素材や項目は公開しない。

### 受け入れ例

1. 承認済みと未承認のスポンサー情報を用意する。
2. スポンサー紹介を開く。
3. 承認済みの情報だけが表示される。
