# 来場者向け情報仕様

## 結論と対象範囲

来場者は、ログインせずに出店情報、メニュー、スポンサー情報を確認できる。この仕様は情報の内容と表示結果を定義し、画面の配置や配色は定義しない。

## 管理データと画面

| 情報           | 必要な項目                                                               | 主な画面       |
| -------------- | ------------------------------------------------------------------------ | -------------- |
| 出店情報       | 出店名、場所、営業時間、案内文                                           | 出店案内       |
| 商品           | 商品名、説明、価格、分類、表示順、販売可否、特定原材料、原材料の確認状態 | メニュー       |
| スポンサー情報 | 承認された名称、紹介文、画像、リンク                                     | スポンサー紹介 |

商品、分類、価格、表示順は[メニュー](../product/menu.md)を正本とする。スポンサーの掲載項目は[`Q-VIS-001`](../meta/questions/Q-VIS-001-sponsor-content.md)で決定する。

## SPEC-VIS-001 出店情報を表示する

関連要件: `REQ-VIS-001`

未ログインの来場者が出店案内を開いたとき、合意した出店場所と営業時間を表示する。来場者のユーザー登録やログインは要求しない。

### 受け入れ例

1. ログインしていない端末で出店案内を開く。
2. 合意した出店場所と営業時間が表示される。

## SPEC-VIS-002 メニューと販売可否を表示する

関連要件: `REQ-VIS-002`、`REQ-INV-001`

メニューには、登録された商品の名称、価格、説明、販売可否を表示する。販売可否は現在の在庫に基づき、色だけに依存せず識別できるようにする。

### 受け入れ例

1. 販売可能な商品と在庫切れの商品を用意する。
2. メニューを開く。
3. 各商品の名称、価格、説明が表示され、在庫切れの商品を文字または記号でも識別できる。

## SPEC-VIS-003 承認されたスポンサー情報を表示する

関連要件: `REQ-VIS-003`

スポンサー紹介には、掲載を承認された情報だけを表示する。承認されていない素材や項目は公開しない。

### 受け入れ例

1. 承認済みと未承認のスポンサー情報を用意する。
2. スポンサー紹介を開く。
3. 承認済みの情報だけが表示される。

## SPEC-VIS-004 商品に含まれる特定原材料を表示する

関連要件: `REQ-VIS-004`

メニューには、商品ごとに含まれる特定原材料を表示する。対象は食品表示基準の特定原材料9品目(えび、かに、カシューナッツ、くるみ、小麦、そば、卵、乳、落花生)である。

対象品目は固定の項目として持たず、追加・変更できる一覧として管理する。カシューナッツの完全義務化(2028年4月1日)のように、対象品目は今後も変わる。

原材料を確認していない商品と、含まれないことを確認した商品を区別して扱う。未確認の商品について、含まれない旨を表示しない。

### 受け入れ例

1. 特定原材料を含む商品、含まないことを確認した商品、未確認の商品を用意する。
2. メニューを開く。
3. 該当する品目が商品ごとに表示され、未確認の商品は確認していないことが分かる。
