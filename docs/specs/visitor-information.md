# 来場者向け情報仕様

## 結論と対象範囲

来場者は、ログインせずに出店情報、メニュー、スポンサー情報を確認できる。この仕様は情報の内容、表示結果、テーマの選択を定義する。

公開サイトの情報はすべて公開サイト自体に含めて配信し、APIから取得しない。来場者向けに在庫や販売可否は表示せず、注文と売り切れの案内は店頭で行う。

## 管理データと画面

| 情報           | 必要な項目                                                           | 表示する場所                 |
| -------------- | -------------------------------------------------------------------- | ---------------------------- |
| 出店情報       | 開催日、一般公開日、営業時間、注文受付の終了時刻、場所、雨天時の場所 | トップの「アクセス」         |
| 商品           | 商品名、説明、価格、分類、表示順、写真、特定原材料、原材料の確認状態 | トップの「お料理」「飲み物」 |
| スポンサー情報 | 承認された名称、紹介文、画像、リンク                                 | トップの「ご協賛」           |

商品、分類、価格、表示順は[メニュー](../product/menu.md)を正本とする。商品名と価格のうち未確定のものは[`Q-VIS-002`](../meta/questions/Q-VIS-002-menu-names-and-prices.md)で決定する。スポンサーの掲載項目は[`Q-VIS-001`](../meta/questions/Q-VIS-001-sponsor-content.md)で決定する。

公開サイトはトップページ1枚に、メニュー、アクセス、ご協賛の区画を縦に並べる。ヘッダーのメニューボタンとフッターのナビゲーションから各区画へ移動できる。フッターのナビゲーションには、`/privacy`と`/terms`へのリンクも置く(`SPEC-SYS-010`)。

## SPEC-VIS-001 出店情報を表示する

関連要件: `REQ-VIS-001`

未ログインの来場者がトップの「アクセス」を開いたとき、次の出店情報と、出店位置を示す地図を表示する。来場者のユーザー登録やログインは要求しない。

| 項目         | 内容                         |
| ------------ | ---------------------------- |
| 開催日       | 2026年10月24日(土)・25日(日) |
| 一般公開     | 10月24日(土)のみ             |
| 営業時間     | 10時から16時まで             |
| 注文受付     | 15時30分まで                 |
| 場所         | 茨城高専 サッカー場          |
| 雨天時の場所 | 体育館                       |

地図の施設名は画像にせず文字で示し、出店位置は地図を見なくても分かるよう文章でも伝える。

### 受け入れ例

1. ログインしていない端末でトップの「アクセス」を開く。
2. 上表の開催日、一般公開日、営業時間、注文受付の終了時刻、場所、雨天時の場所と、出店位置を示す地図が表示される。

## SPEC-VIS-002 メニューを表示する

関連要件: `REQ-VIS-002`

トップの「お料理」と「飲み物」に、商品ごとの写真、名称、価格をカードで表示する。カードを選ぶと商品の詳細を開き、写真、名称、価格、説明、特定原材料(`SPEC-VIS-004`)を表示する。詳細は閉じるボタン、背景の選択、`Esc`キーで閉じ、選んだカードへフォーカスを戻す。

商品情報は公開サイトに含めて配信するため、取得中や取得失敗の状態を持たない。販売可否は表示しない。

### 受け入れ例

1. APIへ接続できない状態でトップを開く。
2. 全商品の写真、名称、価格がカードで表示される。
3. カードを選ぶと説明と特定原材料を含む詳細が開き、閉じると元のカードへフォーカスが戻る。

## SPEC-VIS-003 承認されたスポンサー情報を表示する

関連要件: `REQ-VIS-003`

スポンサー紹介には、掲載を承認された情報だけを表示する。承認されていない素材や項目は公開しない。掲載できる情報がない間は、トップの「ご協賛」とヘッダーのメニューの「Sponsors」欄に「Coming soon」と表示する。

### 受け入れ例

1. 承認済みと未承認のスポンサー情報を用意する。
2. スポンサー紹介を開く。
3. 承認済みの情報だけが表示される。
4. 承認済みの情報がない場合は、「ご協賛」と「Sponsors」欄に「Coming soon」だけが表示される。

## SPEC-VIS-004 商品に含まれる特定原材料を表示する

関連要件: `REQ-VIS-004`

商品の詳細には、特定原材料の使用状況を表示する。対象は食品表示基準の特定原材料9品目(えび、かに、カシューナッツ、くるみ、小麦、そば、卵、乳、落花生)である。

対象品目は固定の項目として持たず、追加・変更できる一覧として管理する。カシューナッツの完全義務化(2028年4月1日)のように、対象品目は今後も変わる。

原材料を確認した商品は、品目ごとに次のいずれかを示し、記号の意味を同じ画面に併記する。

| 記号 | 意味                                               |
| ---- | -------------------------------------------------- |
| ○    | この原材料を使用している                           |
| △    | 調理過程での接触や、使用製品での含有の可能性がある |
| ✕    | 使用していない                                     |

原材料を確認していない商品は品目の一覧を表示せず、確認中であることを示す。未確認の商品について、含まれない旨を表示しない。

### 受け入れ例

1. 特定原材料を使用する商品、含有の可能性がある商品、使用しないことを確認した商品、未確認の商品を用意する。
2. それぞれの商品の詳細を開く。
3. 確認済みの商品は9品目ごとに○△✕と記号の意味が表示され、未確認の商品は確認中であることだけが表示される。

## SPEC-VIS-005 公開ページのテーマを選択する

関連要件: `REQ-VIS-005`

公開ページでは、ヘッダーのテーマボタンから「ライト」「ダーク」「システム」を選択できる。「システム」は端末の配色設定に合わせる。選択中の項目には印を付ける。初期値は「システム」とする。選択は同じブラウザーの`localStorage`へ保存し、ページ移動・再表示後にも適用する。「システム」を選んだ場合は、表示中の端末設定の変更にも追従する。

保存できない環境でも表示中は切り替えられる。保存値が不正な場合は端末設定に合わせる。公開側のテーマはスタッフ画面へ影響しない。

### 受け入れ例

1. ダークを選択して別の公開ページへ移動し、再読み込みしてもダークになる。
2. 「システム」を選び、端末の配色設定を変更すると公開ページも変わる。
3. 保存が拒否された環境でもテーマを切り替えられる。
