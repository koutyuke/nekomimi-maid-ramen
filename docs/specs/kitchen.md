# 調理仕様

## 結論と対象範囲

調理担当者は、確定した注文だけを確認し、調理状況を更新する。調理状況は注文全体に対して一つ持ち、商品ごとには持たない。

## 画面と管理データ

注文一覧・調理状況画面は、注文番号、商品、数量、現在の調理状況を表示し、許可された状況更新を提供する。

調理状況は次の3つである。

| 調理状況 | 意味                                       |
| -------- | ------------------------------------------ |
| 未調理   | 確定した直後の状態。まだ誰も着手していない |
| 調理中   | 調理担当者が着手した状態                   |
| 完成     | 受け渡しできる状態                         |

一覧は未調理と調理中を先に並べ、それぞれ確定した順に表示する。完成した注文は受け渡し画面で扱う。

## SPEC-KIT-001 確定した注文だけを表示する

関連要件: `REQ-KIT-001`、`REQ-SAL-005`

調理画面には確定した注文の番号、商品、数量、現在の調理状況を表示する。注文候補や確定に失敗した内容は表示しない。

### 受け入れ例

1. 注文候補と確定注文をそれぞれ作成する。
2. 調理画面を開く。
3. 確定注文だけが表示され、注文候補は表示されない。

## SPEC-KIT-002 許可された順序で調理状況を更新する

関連要件: `REQ-KIT-002`、`REQ-HAND-001`

調理状況は未調理から調理中へ、調理中から完成へ進める。着手を取り消す場合に限り、調理中から未調理へ戻せる。完成から前の状態へは戻せない。

更新結果は、調理担当者と受け渡し担当者が同じ内容として確認できる。取り消し済みの注文は調理対象にならず、調理状況を更新できない。

### 受け入れ例

1. 確定注文を未調理から調理中、調理中から完成へ順に変更する。
2. 調理画面と受け渡し画面に同じ状態が表示される。
3. 調理中から未調理へ戻す操作が成立する。
4. 完成から調理中へ戻す操作と、未調理から完成へ飛ばす操作は成立しない。
5. 取り消し済みの注文は調理画面に表示されず、調理状況を更新できない。
