# 調理仕様

## 結論と対象範囲

調理担当者は、確定した注文だけを確認し、調理状況を更新する。必要な状態、遷移順序、戻す操作、一覧の並び順は[`Q-KIT-001`](../meta/questions/Q-KIT-001-cooking-status.md)で決定する。

## 画面と管理データ

注文一覧・調理状況画面は、注文番号、商品、数量、現在の調理状況を表示し、許可された状況更新を提供する。

## SPEC-KIT-001 確定した注文だけを表示する

関連要件: `REQ-KIT-001`、`REQ-SAL-005`

調理画面には確定した注文の番号、商品、数量、現在の調理状況を表示する。注文候補や確定に失敗した内容は表示しない。

### 受け入れ例

1. 注文候補と確定注文をそれぞれ作成する。
2. 調理画面を開く。
3. 確定注文だけが表示され、注文候補は表示されない。

## SPEC-KIT-002 許可された順序で調理状況を更新する

関連要件: `REQ-KIT-002`、`REQ-HAND-001`

調理担当者は、合意した状態と遷移だけを選択できる。更新結果は、調理担当者と受け渡し担当者が同じ内容として確認できる。

### 受け入れ例

1. 確定注文の調理状況を許可された次の状態へ変更する。
2. 調理画面と受け渡し画面を確認する。
3. 両画面に同じ状態が表示される。
4. 許可されていない状態への変更は成立しない。
